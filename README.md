# Problem Statement

Modern cloud environments generate huge amounts of telemetry such as network traffic, IAM logs and resource activity logs. Existing intrusion detection systems analyze events independently and cannot effectively detect sophisticated multi-stage attacks. They also provide little explanation for why a threat is detected.

---

# Objectives

- Build a heterogeneous graph from cloud telemetry.
- Detect cyber threats using Graph Neural Networks.
- Explain every prediction using GNNExplainer.
- Implement the solution using Microsoft Azure services.
- Develop an interactive SOC dashboard.
